# Integra-Stock
SISTEMA DE ESTOQUE INTELIGENTE MRO
Integração inteligente entre manutenção e controle de estoque
1. Sobre o projeto
O Sistema de Estoque Inteligente MRO é um projeto de desenvolvimento web que tem como objetivo facilitar o gerenciamento de peças, materiais e solicitações de manutenção dentro de empresas. A proposta surgiu da necessidade de melhorar a comunicação entre os setores de manutenção e estoque, reduzindo falhas de comunicação, atrasos e dificuldades no controle de materiais.
2. Objetivos
•	Integrar os setores de manutenção e estoque em uma única plataforma.
•	Facilitar o controle de peças e materiais.
•	Melhorar a organização das solicitações de manutenção.
•	Identificar produtos com estoque baixo.
•	Tornar os processos internos mais eficientes.
•	Utilizar recursos de inteligência artificial para auxiliar no controle de estoque.
3. Funcionalidades principais
1.	Controle de acesso: áreas de acesso distintas para funcionários da manutenção, estoque e gerência.

4.	Dashboard: painel com informações sobre solicitações, peças, ordens de serviço e itens com estoque baixo.
5.	Gerenciamento de estoque: cadastro e consulta de peças com código MRO, descrição, quantidade, localização e estoque mínimo.
6.	Solicitações de materiais: comunicação entre os setores de manutenção e estoque.
7.	Ordens de serviço: acompanhamento das atividades de manutenção.
8.	Inteligência artificial: proposta de uso de câmera e IA para auxiliar na identificação e contagem de materiais.

6. Público-alvo
O sistema é destinado principalmente a empresas que trabalham com manutenção, controle de materiais e gerenciamento de peças, especialmente aquelas que precisam melhorar a integração entre seus setores.
